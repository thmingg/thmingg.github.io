What is Swift ?

Swift is a compiled programming language for all Apple platform. It mainly use in Apple ecosystems: iOS, macOS, watchOS, tvOS (SwiftUI). It is a Multi-Paradigm Language thats support Object-Oriented Programming (OOP), Protocol-Oriented Programming (POP) and Functional Programming.

Swift Basics

Constant and Variables

Variable - You can change the value whenever you want.

Constant - You cannot change the values once they are set.

1
2

let hello = "Hello" // Constant
var world = "World" // Variable

Type

Type Safety

Swift allow us create variables as strings and integers, but also other data types too. Swift can figure out the type of the variable based on its value. You cannot change the type of the variable later on.

Example :

1

var aloha = "Aloha"

Since we already set the value of aloha = “Aloha” which is a string. So that we can’t write this :

1

aloha = 1234

Type Annotation

Common Reasons that we need to use type annotation

  1. You want to use different type from swift’s default
  2. You don’t want to assign a value now.
  3. Swift can’t figure out which type should be use

The first of those will be happen when you fetch data from the internet. Swift would not know the type if its some custom data type.

The second situation is quite common. Here is the example :

1
2

//If you don't specify Double, it will be integer as default
var width: Double = 18

When you don’t want to assign value to a variable when its declaration :

1

var noValue: String

String

String interpolation

I most of the application, we use string to show data, messages to user. Most of the time, the message isn’t static string, because we want to so some relevant data to the user which is dynamic. So that Swift support String interpolation to combine static string with variable (dynamic).Here’s the example :

1
2

var name = "Peter"
var greeting = "Hello \(name) !" //outputs : Hello Peter !
